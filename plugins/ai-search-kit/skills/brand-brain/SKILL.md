# Brand Brain — ให้ AI เรียนรู้แบรนด์ แล้วจำไว้

> 📍 ในคลาส: **Workshop 4 ขั้นที่ 1 · Brand Brain** · ขั้นต่อไป Workshop 4 ขั้นที่ 2: `/ai-content-writer`
> ตอบทุกครั้งให้ขึ้นบรรทัดแรกด้วย `📍 Workshop 4 ขั้นที่ 1 · Brand Brain` และเมื่อแนะนำขั้นต่อไป ให้เรียงตามลำดับ Workshop ในคลาส (1 prompt-finder → 2 ai-visibility-check → 3 site-readiness-audit → 4 brand-brain → ai-content-writer → ai-citable-page-check)

AI เขียนเก่ง แต่ถ้าไม่รู้จักแบรนด์จริง จะเขียนแบบกว้าง ๆ หรือเดาข้อมูลผิด Brand Brain แก้ปัญหานี้: AI **เรียนรู้** แบรนด์และสินค้าจาก 2 ทาง แล้ว **จำไว้เป็นไฟล์เดียว** ที่ผู้ใช้เป็นเจ้าของ เอาไปใช้กับงานเขียนทุกชิ้น
skill นี้**ไม่ใช่การสัมภาษณ์** — AI ทำงานเอง แล้วสรุปเฉพาะช่องที่หาไม่ได้ให้ผู้ใช้เติม

## 1. รับของตั้งต้น (ขอรวดเดียว)
- ชื่อแบรนด์ + **เว็บไซต์ทางการ** + สินค้า/บริการที่จะโฟกัส
- **ข้อมูลที่ทีมมี** (แนบหรือวางได้เลย ไม่ต้องจัดรูปแบบ): brand book, product sheet, ราคา/โปรโมชัน, FAQ, คำถามที่ลูกค้าถามบ่อย, รีวิว, เอกสารนำเสนอ
- คู่แข่ง 3–5 ราย (ถ้ามี Prompt Set จาก `prompt-finder` ใช้ชื่อคู่แข่งและหัวข้อจากไฟล์นั้น)
- ถ้าผู้ใช้ไม่มีเอกสารเลย → เริ่มจากเว็บไซต์อย่างเดียวได้

### 1.1 คัดข้อมูลลับก่อนรวม (บังคับ — ทำก่อนอ่านเอกสารเข้าไฟล์)
ถ้าผู้ใช้แนบเอกสาร ให้ลิสต์ชื่อเอกสารทั้งหมด แล้วถาม**ทีละเอกสาร**ในข้อความเดียว:
"แต่ละไฟล์เป็นแบบไหน — **เผยแพร่ได้** (ลงเว็บ/ให้ลูกค้าเห็นได้) / **ภายใน** (ใช้อ้างอิงได้ แต่ห้ามลงในงานที่เผยแพร่) / **ห้ามเผยแพร่** (ไม่ต้องจดเลย)"
- ผู้ใช้ไม่ตอบ หรือไม่แน่ใจ = ถือเป็น **ภายใน** จนกว่าจะบอก (ห้ามเดาว่าเผยแพร่ได้)
- เอกสารเดียวมีทั้งสองแบบ (เช่น ราคาขายปลีกกับราคาดีลเลอร์) → ถามเป็นหัวข้อ/หน้าในเอกสารนั้น
- ข้อมูลจากเว็บทางการ = เผยแพร่ได้อยู่แล้ว ไม่ต้องถาม
- **ห้ามรวมข้อมูลจากเอกสารเข้าไฟล์ก่อนได้คำตอบข้อนี้**

## 2. เรียนรู้ (AI ทำเอง)
**ทาง A — ข้อมูลที่ผู้ใช้ให้:** อ่านทุกไฟล์ ดึงข้อเท็จจริงออกมาตามโครงใน `references/brand-brain-template.md`
**ทาง B — ศึกษาจากแหล่งทางการ:** เปิดหน้าเว็บทางการ (หน้าแรก · หน้าสินค้า/บริการหลัก · ราคา · FAQ · เกี่ยวกับเรา · ติดต่อ · ข่าว/ประกาศ) + ช่องทางทางการอื่นที่เว็บลิงก์ไป
- ใช้เครื่องมือค้นเว็บ/เปิดเว็บที่มีอยู่ ถ้าเปิดไม่ได้ (เครือข่ายถูกจำกัด) → บอกผู้ใช้ตรง ๆ และขอให้วางข้อความจากหน้าสำคัญ 3–5 หน้าแทน
**ทาง C (เสริม) — สิ่งที่คนอื่นพูดถึงเรา:** สื่อ รีวิว ชุมชน ใช้เป็น "มุมมองภายนอก" แยกไว้ต่างหาก **ไม่นับเป็นข้อเท็จจริงของแบรนด์**

ทุกข้อเท็จจริงต้องมีป้าย **ที่มา + สถานะ** ต่อบรรทัด เช่น `[ทีมให้ · เผยแพร่ได้] (product-sheet.pdf)`:
- ที่มา: `[ทางการ]` = เจอบนเว็บ/เอกสารทางการ (ใส่ URL หรือชื่อไฟล์) · `[ทีมให้]` = มาจากข้อมูลที่ผู้ใช้ให้ แต่ยังไม่เจอบนเว็บ · `[ต้องยืนยัน]` = ข้อมูลขัดกัน เก่า หรือไม่แน่ใจ → บอกว่าขัดกับอะไร
- สถานะ: `เผยแพร่ได้` / `ภายใน` ตามคำตอบข้อ 1.1 (ข้อมูล "ห้ามเผยแพร่" ไม่จดลงไฟล์ไหนเลย)
- ข้อมูลที่ทีม/ผู้มีอำนาจยืนยันภายหลัง ให้ใส่ผู้ยืนยันและวันที่ เช่น `[ทางการ/ทีมให้ · เผยแพร่ได้] ยืนยันโดย ทีมการตลาด 11 ต.ค. 2569`

## 3. จำไว้เป็นไฟล์
เขียน `brand-brain-<แบรนด์>.md` ตามโครงใน `references/brand-brain-template.md` (ข้ามหัวข้อที่ไม่เกี่ยวได้ แต่อย่าแต่งเติม) — **ใส่เฉพาะบรรทัดที่ "เผยแพร่ได้"** ไฟล์นี้คือไฟล์ที่แนบตอนสั่งเขียน
ถ้ามีข้อมูล "ภายใน" ให้แยกเป็นอีกไฟล์ `brand-brain-<แบรนด์>-internal.md` (โครงเดียวกัน หัวไฟล์เขียนว่า "ภายใน — ห้ามแนบตอนสั่งเขียน ห้ามคัดลอกลงงานที่เผยแพร่") · ใช้แค่ตรวจข้อเท็จจริง/ความสอดคล้อง
ถ้าผู้ใช้ใช้ Cowork/Claude Code ให้บันทึกในโฟลเดอร์โปรเจกต์ (ไฟล์กลางที่ skill อื่นอ่าน) · ถ้าใช้แชตธรรมดา ให้ส่งเป็นไฟล์ดาวน์โหลด

## 4. ส่งผล (ในแชต สั้น ๆ)
- AI เรียนรู้อะไรได้บ้าง: จำนวนข้อเท็จจริงแยกตามป้าย ทางการ / ทีมให้ / ต้องยืนยัน · กี่บรรทัดเผยแพร่ได้ / กี่บรรทัดแยกไปไฟล์ภายใน
- **ช่องว่างที่ต้องเติม** ไม่เกิน 5 ข้อ เรียงตามผลต่อการเขียน content (เช่น "ยังไม่มีราคาทางการบนเว็บ — AI จะไปเอาราคาจากเว็บอื่นมาพูดแทน")
- **ข้อมูลที่ขัดกัน** ระหว่างเอกสารทีมกับเว็บ (ถ้ามี) — เป็นสิ่งที่ต้องแก้บนเว็บด้วย เพราะ AI อ่านเว็บ
- วิธีใช้ต่อ: แนบ `brand-brain-<แบรนด์>.md` (ไฟล์เผยแพร่ได้) ทุกครั้งที่ให้ AI เขียนงาน หรืออัปโหลดเข้า Claude Project · **ไม่แนบ/ไม่อัปโหลดไฟล์ -internal** · ใช้กับ `ai-content-writer` และ `ai-citable-page-check` · ทบทวนทุกเดือนหรือเมื่อมีสินค้า/ราคาใหม่
- ปิดท้ายด้วยคำสั่งถัดไปในกรอบ code เติมชื่อไฟล์ให้แล้ว เช่น `/ai-content-writer เขียนหน้าใหม่ตอบ prompt "<prompt จาก visibility-<แบรนด์>.md>" ใช้ brand-brain-<แบรนด์>.md`

## กติกา
- **ห้ามแต่งข้อเท็จจริง** ตัวเลข ราคา สเปก ส่วนผสม รางวัล หรือคำกล่าวอ้าง — ไม่เจอ = เขียนว่า "ไม่พบ" แล้วใส่ในช่องว่าง
- ข้อมูลคู่แข่งใส่เฉพาะที่ตรวจได้จากแหล่งทางการของคู่แข่ง พร้อม URL และวันที่ · ไม่คัดลอกข้อความของคู่แข่ง
- สุขภาพ / การเงิน / อาหาร-เครื่องดื่ม / กฎหมาย: แยกหัวข้อ "คำกล่าวอ้างที่ใช้ได้" กับ "ข้อห้าม" ให้ชัด ใช้ได้เฉพาะคำกล่าวอ้างที่มีในเอกสารทางการ
- ข้อมูล "ห้ามเผยแพร่" → ไม่จดลงไฟล์ไหนเลย · ข้อมูล "ภายใน" → อยู่ในไฟล์ -internal เท่านั้น ไม่ปนในไฟล์หลัก
- อัปเดตไฟล์เมื่อผู้ใช้ให้ข้อมูลทางการที่ใหม่กว่า: แก้บรรทัดเดิม ใส่ป้าย `[ทางการ/ทีมให้]` + ผู้ยืนยัน + วันที่ และย้ายค่าเก่าไปหัวข้อ 12 "ข้อมูลที่ขัดกัน" ถ้ายังมีที่อื่นใช้ค่าเก่าอยู่
- ใส่วันที่อัปเดตและแหล่งที่มาทุกครั้ง (AI ใช้ข้อมูลเก่าคือความเสี่ยง)
- อ้างอิงแนวคิด: *AI SEO For Dummies* (Nathan Gotch, Wiley 2026) บทที่ 12–13 และ 16 — แบรนด์ต้องประกาศข้อมูลทางการให้ชัดและตรงกันทุกที่ ไม่งั้นแหล่งอื่นจะพูดแทน (สรุปด้วยคำของเรา ไม่คัดลอกข้อความจากหนังสือ)
