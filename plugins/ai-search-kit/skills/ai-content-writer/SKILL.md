# AI Content Writer — เขียนให้ AI มีเหตุผลเลือกเรา

AI แนะนำแบรนด์ที่มีคำตอบชัด มีหลักฐาน และตรงเกณฑ์ที่ผู้ถามใช้ตัดสินใจ skill นี้เขียน content แบบนั้นจาก **ข้อมูลจริงใน Brand Brain** ไม่ใช่ content ทั่วไปที่ใครก็เขียนได้
อ่าน `references/content-blueprint.md` ก่อนเริ่ม

## 0. อัปเดต Brand Brain ก่อน (ถ้ามีข้อมูลใหม่กว่า)
ถ้าผู้ใช้ให้ข้อมูลทางการหรือข้อมูลที่ทีมยืนยันแล้ว ซึ่งใหม่กว่าหรือขัดกับ Brand Brain (ราคา โปร สเปก เงื่อนไข) — **อัปเดตบรรทัดนั้นใน Brand Brain ก่อน แล้วค่อยเขียน**:
- ใส่ป้าย `[ทางการ/ทีมให้]` + **ใครยืนยัน** (ชื่อ/ทีม/เอกสาร) + **วันที่** · ค่าเก่าย้ายไปหัวข้อ 12 "ข้อมูลที่ขัดกัน" ถ้ายังมีที่อื่นใช้อยู่
- ถามสถานะ เผยแพร่ได้ / ภายใน ถ้ายังไม่รู้ (ภายใน → ไฟล์ `brand-brain-<แบรนด์>-internal.md` ไม่ใช้ในงานที่เผยแพร่)
- ผู้ใช้บอกแค่ "ยืนยันแล้ว" แต่ไม่บอกใคร/เมื่อไร → ถาม 1 ครั้ง ถ้าไม่ได้คำตอบให้ติด `[ต้องยืนยัน]`
- ใน Cowork/Claude Code แก้ไฟล์ในโฟลเดอร์โปรเจกต์ · แชตธรรมดา ส่งบรรทัดที่แก้ให้ผู้ใช้วางทับ

## 1. รับโจทย์
- **prompt เป้าหมาย** 1 ข้อ (หรือ 2–3 ข้อในหัวข้อเดียวกัน) + สถานะจาก `ai-visibility-check` (Absent / Chasing) + เว็บที่ถูกอ้าง + แบรนด์ที่ถูกแสดงแทน
- **Brand Brain** ของแบรนด์ — ใช้เฉพาะ `brand-brain-<แบรนด์>.md` (ข้อมูลเผยแพร่ได้) **ไม่โหลด/ไม่ขอไฟล์ -internal** · ถ้าผู้ใช้แนบไฟล์ -internal มา ให้บอกว่าจะไม่ใช้ข้อมูลในนั้นเขียน (ถ้ายังไม่มี Brand Brain → แนะนำให้รัน `brand-brain` ก่อน หรือขอข้อมูลสินค้าที่เกี่ยวกับ prompt นี้โดยตรง)
- **โหมด:**
  - **สร้างหน้าใหม่** — prompt ที่แพ้ และเว็บเรายังไม่มีหน้าที่ตอบ
  - **ต่อยอดหน้าเดิม** — ใส่ URL หรือวางเนื้อหาหน้าเดิม (ใช้กับจุดที่พัฒนาได้ และกับหน้าที่ AI อ้างอยู่แล้วแต่ยังไม่เลือกเรา)
ถ้าผู้ใช้ไม่ระบุโหมด: มีหน้าใกล้เคียงอยู่แล้ว → ต่อยอด · ไม่มี → สร้างใหม่

## 2. วางงานของหน้า (ก่อนเขียน)
เขียน 1 ประโยค: หน้านี้ตอบ **prompt** อะไร · ผู้ถามอยู่ขั้นไหน · **เกณฑ์ตัดสินใจ** อะไรบ้าง · อยากให้ทำอะไรต่อ
แล้วเช็ก:
- หน้าที่ถูกอ้าง/แบรนด์ที่ชนะมีอะไรที่เราไม่มี (ตาราง ตัวเลข รีวิว คำตอบตรง ความสด) — เปิดดูได้ถ้ามีเครื่องมือเปิดเว็บ ถ้าไม่ได้ให้ถามผู้ใช้
- Brand Brain มีข้อเท็จจริงพอตอบทุกเกณฑ์ไหม → เกณฑ์ไหนข้อมูลไม่พอ ให้บอกผู้ใช้ก่อนเขียน (อย่าเติมเอง)

## 3. เขียน
ตาม `references/content-blueprint.md`:
- **โหมดสร้างใหม่:** outline → ร่างเต็ม
- **โหมดต่อยอด:** ตารางว่า "ส่วนไหนเก็บไว้ · ส่วนไหนแก้ · ส่วนไหนเพิ่ม" + ข้อความใหม่เฉพาะส่วนที่แก้/เพิ่ม (ไม่เขียนทับทั้งหน้าโดยไม่จำเป็น)
น้ำเสียงตาม Brand Brain หัวข้อ 8 · คำกล่าวอ้างตามหัวข้อ 9

## 4. ส่งผล
1. **งานของหน้า** 1 ประโยค + prompt ที่หน้านี้ตอบ
2. **ร่าง content** (Markdown — ตาราง/หัวข้อพร้อมวางลงเว็บ) หรือรายการแก้ไขสำหรับโหมดต่อยอด
3. **แผนผัง prompt → ส่วนของหน้า** (เกณฑ์แต่ละข้อตอบอยู่ย่อหน้าไหน)
4. **ข้อเท็จจริงที่ต้องยืนยันก่อนเผยแพร่** (ทุกตัวเลข/ราคา/สเปก/คำกล่าวอ้างที่ป้ายใน Brand Brain ไม่ใช่ [ทางการ])
5. **งานนอกหน้า** 1–3 ข้อ (เช่น ส่งข้อมูลให้เว็บรีวิวที่ AI อ้าง) ถ้าเกี่ยวข้อง
6. ขั้นต่อไป: ตรวจด้วย `ai-citable-page-check` → เผยแพร่ → วัดซ้ำ prompt เดิมหลัง 1–2 สัปดาห์ · ปิดท้ายด้วยคำสั่งถัดไปในกรอบ code เติมชื่อไฟล์ให้แล้ว เช่น `/ai-citable-page-check ตรวจร่าง <ชื่อไฟล์ร่าง>.md ว่า AI จะหยิบไปตอบ prompt "<prompt>" ได้ไหม ใช้ brand-brain-<แบรนด์>.md` (ถ้าร่างไม่ได้บันทึกเป็นไฟล์ ให้บอกว่าแนบร่างนี้ไปด้วย)

## กติกา
- **ใช้เฉพาะข้อเท็จจริงที่ "เผยแพร่ได้" จาก Brand Brain หรือที่ผู้ใช้ให้** — ไม่มีข้อมูล = เขียน `[ต้องเติม: …]` ไว้ในร่าง ห้ามแต่ง · ข้อมูลที่ป้าย `ภายใน` หรือมาจากไฟล์ -internal ห้ามใส่ในร่าง แม้ผู้ใช้จะแนบมา
- ข้อมูลคู่แข่งในตารางเทียบ: เฉพาะที่ตรวจได้จากแหล่งทางการ ใส่แหล่งและวันที่ · เขียนอย่างเป็นธรรม ไม่โจมตี
- 1 หน้า = 1 งานหลัก · ไม่ปั๊มหน้าซ้ำ ๆ เปลี่ยนแค่ชื่อเมือง/รุ่น (Google ถือเป็น scaled content abuse)
- สุขภาพ / อาหาร-เครื่องดื่ม / การเงิน: ใช้เฉพาะคำกล่าวอ้างที่อยู่ในเอกสารทางการ ใส่หมายเหตุให้ทีมกฎหมาย/regulatory ตรวจ
- เขียนให้คนอ่านก่อน — Google ระบุว่าไม่ต้องทำอะไรพิเศษเพื่อ AI features นอกจาก content ที่มีประโยชน์และเข้าถึงได้; สิ่งที่ skill นี้เน้น (คำตอบชัด ตาราง หลักฐาน) ช่วยทั้งคนและ AI
- อ้างอิงแนวคิด: *AI SEO For Dummies* (Nathan Gotch, Wiley 2026) บทที่ 11, 12, 14, 23 (โครงหน้า, ชุดคำตอบช่วงตัดสินใจ, งานของหน้า, FAQ) + Google Search Central: AI features and your website / helpful content — สรุปด้วยคำของเรา ไม่คัดลอกข้อความจากหนังสือ
