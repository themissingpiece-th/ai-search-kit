# Content Blueprint — โครงหน้าที่ AI หยิบไปตอบได้

หลักคิดจาก *AI SEO For Dummies* บทที่ 11, 12, 14, 23 (สรุปเอง) + Google Search Central
ใช้เป็นโครงตั้งต้น ปรับตามประเภทหน้าที่ AI/Google ให้รางวัลอยู่ (ดูจากเว็บที่ถูกอ้าง)

## เลือกประเภทหน้าให้ตรง prompt
| prompt แบบนี้ | ประเภทหน้า |
|---|---|
| "…รุ่นไหน/ยี่ห้อไหนดี สำหรับ…" (Comparison) | หน้าเปรียบเทียบ / คู่มือเลือก "เหมาะกับใคร" |
| "A กับ B ต่างกันยังไง" | หน้า A vs B (เขียนอย่างเป็นธรรม) |
| "[แบรนด์] ราคา / เงื่อนไข / สเปก" (Decision) | หน้าสินค้า / ราคา / FAQ ทางการ |
| "[แบรนด์] ข้อเสีย / ดีไหม" | หน้า FAQ ที่ตอบตรง + หลักฐาน + รีวิวจริง |
| "ควรเลือกแบบไหน / ต้องดูอะไร" (Evaluation) | คู่มือเกณฑ์การเลือก |

## โครงหน้า (โหมดสร้างใหม่)
1. **H1** = คำถามหรือคำตอบของ prompt ในภาษาที่ลูกค้าใช้
2. **คำตอบสั้นต้นหน้า** 2–3 ประโยค — ตอบตรง ระบุว่าเหมาะกับใคร/ไม่เหมาะกับใคร (อ่านเดี่ยว ๆ แล้วเข้าใจ)
3. **กล่อง "สรุปเร็ว"** 3–5 บรรทัด ตามเกณฑ์ตัดสินใจ
4. **ส่วนละเกณฑ์** (H2 ต่อเกณฑ์ เช่น ชาร์จ · ระยะวิ่ง · ประกันแบต · ค่าใช้จ่าย) — แต่ละส่วน: คำตอบ → ตัวเลข/หลักฐาน (ติดแหล่ง) → ข้อจำกัดที่ควรรู้
5. **ตารางเปรียบเทียบ** (เป็นตาราง HTML ไม่ใช่รูป) — แถว = เกณฑ์ · คอลัมน์ = ตัวเลือก · ใส่แหล่งและวันที่ข้อมูล
6. **"เลือกแบบนี้ถ้า…"** — ช่วยผู้อ่านตัดสินใจตามสถานการณ์
7. **FAQ** 3–6 ข้อ จากคำถามจริง (Brand Brain หัวข้อ 6 / prompt ที่เกี่ยว) — ประโยคแรกตอบเลย ไม่เกิน ~3 ประโยค แสดงบนหน้า
8. **หลักฐาน/ความน่าเชื่อถือ** — รีวิว รางวัล การรับรอง ใครเขียน/ตรวจ
9. **วันที่อัปเดต** + ลิงก์ภายในไปหน้าสินค้า/ราคา/ติดต่อ
10. CTA ที่ตรงกับขั้นของผู้อ่าน

## โหมดต่อยอดหน้าเดิม — เช็กทีละข้อ
| เช็ก | ถ้าไม่ผ่าน ให้ทำ |
|---|---|
| ย่อหน้าแรกตอบ prompt ตรงไหม | เขียนคำตอบสั้นใหม่ไว้บนสุด |
| ครอบคลุมเกณฑ์ตัดสินใจครบไหม (เทียบกับหน้าที่ชนะ) | เพิ่ม H2 ของเกณฑ์ที่ขาด |
| มีตัวเลข/หลักฐานติดคำอ้างไหม | เติมจาก Brand Brain หรือใส่ `[ต้องเติม]` |
| มีตารางเปรียบเทียบไหม | เพิ่มตาราง |
| ข้อมูลยังใหม่ไหม (ราคา รุ่น โปร) | อัปเดต + ใส่วันที่ |
| มี FAQ จากคำถามจริงไหม | เพิ่ม FAQ |
| เนื้อหาหลักอยู่ใน HTML ไม่ต้องรอ JavaScript/ไม่ซ่อนในรูป | ส่งต่อ `site-readiness-audit` |
ส่งผลเป็นตาราง เก็บ / แก้ / เพิ่ม + ข้อความใหม่เฉพาะส่วนที่เปลี่ยน

## เขียนอย่างไรให้ "เป็นของเรา"
- ใช้ข้อเท็จจริงเฉพาะของแบรนด์ (ตัวเลข ประสบการณ์ เคส การทดสอบ) — สิ่งที่คู่แข่งเขียนเหมือนไม่ได้
- ประโยคสั้น ย่อหน้าละ 1 ประเด็น อ่านแยกท่อนแล้วยังเข้าใจ (AI มักหยิบไปทีละท่อน)
- เรียกชื่อแบรนด์/สินค้าแบบเดียวกันทั้งหน้า ตรงกับ Brand Brain
- ไม่ยัดคำ ไม่ใส่ปีในหัวข้อถ้าไม่จำเป็น ไม่อวดเกินหลักฐาน
