# จากผลวัด → ควรทำอะไร และทำอย่างไร

ใช้หลังรัน `scripts/analyze.py` · อ่านทีละ prompt แล้วจับคู่กับ "อาการ" ด้านล่าง (1 prompt อาจมีหลายอาการ)
หลักคิดจาก *AI SEO For Dummies* บทที่ 5, 7 (วัด SoV และ citation gap แยกแพลตฟอร์ม/ขั้น), 10–12, 14 (เว็บและ content), 16–20 (สัญญาณนอกเว็บ) — สรุปด้วยคำของเรา

## สถานะต่อ prompt × แพลตฟอร์ม
- **Lead** — เราถูกเอ่ยบ่อยเท่าหรือมากกว่าคู่แข่งที่ถูกเอ่ยบ่อยที่สุด → รักษาไว้ ดูว่าข้อมูลถูกไหม
- **Chasing** — ถูกเอ่ยบ้าง แต่น้อยกว่าผู้นำ หรืออยู่ท้ายรายการ → **จุดที่พัฒนาได้** (ต่อยอด ไม่ใช่เริ่มใหม่)
- **Absent** — ไม่ถูกเอ่ยเลย ทั้งที่มีแบรนด์อื่นถูกเอ่ย → **จุดที่แพ้**

## อาการ → สิ่งที่ควรทำ → วิธีทำ

### A. Absent เกือบทุกแพลตฟอร์ม + เว็บที่ถูกอ้างเป็นเว็บอื่นทั้งหมด
**ควรทำ:** สร้างหน้าที่ตอบ prompt นี้ตรง ๆ + เข้าไปอยู่บนแหล่งที่ AI อ้าง
**ทำอย่างไร:**
1. ดู `cited_domains` ของ prompt นี้ — แยกประเภท: สื่อ / รีวิว / ตลาดซื้อขาย / ชุมชน / เว็บคู่แข่ง
2. เปิดหน้าที่ถูกอ้าง 2–3 หน้า ดูว่าตอบเกณฑ์ตัดสินใจอะไร มีตาราง/ตัวเลขอะไรที่เราไม่มี
3. สร้างหน้าใหม่บนเว็บเรา (เปรียบเทียบ / "เหมาะกับใคร" / คู่มือเลือก) ที่ตอบเกณฑ์ใน prompt ตั้งแต่ย่อหน้าแรก → ส่งต่อ `ai-content-writer`
4. นอกเว็บ: ติดต่อแหล่งที่ถูกอ้างซ้ำ (บทความ best-of, รีวิว, ชุมชน) ด้วยข้อมูล/หลักฐานที่เขาใช้ได้จริง
**ส่งต่อ:** `ai-content-writer` (หน้าใหม่) · `action-plan-30d` (งานนอกเว็บ)

### B. Chasing — ถูกเอ่ยแต่น้อยหรืออยู่ท้าย
**ควรทำ:** ปรับหน้าที่มีอยู่ให้ AI มีเหตุผลเลือกเราเร็วขึ้น
**ทำอย่างไร:**
1. หาหน้าบนเว็บเราที่ใกล้ prompt นี้ที่สุด (ถ้า `our_site_cited` > 0 ใช้หน้านั้น)
2. เทียบกับแบรนด์ที่ Lead: เขามีอะไรที่เราไม่มี — ตาราง, ตัวเลข, รีวิว, คำตอบตรงต้นหน้า, ความสดของข้อมูล
3. เติมคำตอบสั้นต้นหน้า + ตารางเทียบตามเกณฑ์ + หลักฐานติดคำอ้าง + FAQ จากคำถามจริง → อัปเดตวันที่
**ส่งต่อ:** `ai-content-writer` (โหมดต่อยอดหน้าเดิม) → `ai-citable-page-check`

### C. Absent เฉพาะบางแพลตฟอร์ม
| แพลตฟอร์มที่หาย | สาเหตุที่ควรเช็กก่อน | วิธีเช็ก |
|---|---|---|
| Google AI Overviews / AI Mode | หน้าไม่ติด index, noindex/nosnippet, เนื้อหาต้องรอ JavaScript | `site-readiness-audit` + Google Search Console (URL Inspection) |
| ChatGPT | บล็อก OAI-SearchBot ใน robots.txt หรือ firewall, หน้าไม่อยู่ใน Bing | `site-readiness-audit` (ทดสอบ bot) + Bing Webmaster Tools |
| Gemini | เหมือน Google + ข้อมูลแบรนด์บนแหล่งภายนอกไม่ตรงกัน | `site-readiness-audit` + ตรวจ Brand Brain หัวข้อ 12 |
ถ้าเทคนิคผ่านหมด → ถือเป็นอาการ A หรือ B ของแพลตฟอร์มนั้น (แหล่งที่แต่ละแพลตฟอร์มอ้างต่างกัน — ดู `cited_domains` แยกแพลตฟอร์ม)

### D. Branded — AI พูดถึงเราผิด / ข้อมูลเก่า / น้ำเสียงลบ
**ควรทำ:** ทำให้ข้อมูลทางการชัดและตรงกันทุกที่
**ทำอย่างไร:**
1. อ่าน `answer_text` ของ prompt branded — จดประโยคที่ผิด (ราคา สเปก เงื่อนไข ข้อเสียที่ไม่จริง)
2. หาว่าข้อมูลผิดมาจากไหน (ดู `cited_domains`) — เว็บเราเองเก่า? เว็บอื่นเก่า?
3. แก้หน้าทางการบนเว็บเรา (ราคา / FAQ / นโยบาย) ให้ชัด มีวันที่อัปเดต · ขอให้เว็บภายนอกแก้ถ้าเป็นข้อมูลผิดชัดเจน
4. บันทึกลง Brand Brain หัวข้อ 10 "สิ่งที่ AI ยังพูดผิด"
**ส่งต่อ:** `brand-brain` (อัปเดต) · `ai-content-writer` (หน้า FAQ/ราคา)
⚠️ สินค้าสุขภาพ / อาหาร / การเงิน: ข้อมูลผิดเรื่องส่วนผสม สรรพคุณ ราคา ดอกเบี้ย = ลำดับความสำคัญสูงสุด

### E. หัวข้อทั้งหัวข้อแพ้ (mention rate ของหัวข้อต่ำกว่าหัวข้ออื่นมาก)
**ควรทำ:** มองเป็นช่องว่างระดับหัวข้อ ไม่ใช่รายข้อ — ทำ hub ของหัวข้อนั้น (หน้าหลัก + หน้าย่อยตามเกณฑ์) และรวมหลักฐานของหัวข้อไว้ที่เดียว
**ส่งต่อ:** `action-plan-30d`

### F. Lead แล้ว
**ควรทำ:** รักษา — เช็กว่าข้อมูลที่ AI พูดถูกต้อง อัปเดตหน้าทุกเดือน และวัดซ้ำด้วยถ้อยคำเดิม

## จัดลำดับ (เลือกมาไม่เกิน 5 งาน)
คะแนน = คะแนน prompt จาก Prompt Set (ถ้ามี) × ระยะห่างจากผู้นำ × ความง่าย
- ทำก่อน: Branded ที่ข้อมูลผิด (D) → Chasing ใน Comparison/Decision (B — ได้ผลเร็วสุด) → Absent ที่มีแหล่งอ้างชัด (A) → ปัญหาเทคนิค (C)
- ทุกงานต้องเขียนได้ว่า "เสร็จ" หน้าตาเป็นยังไง และวัดซ้ำเมื่อไร

## ข้อควรระวังตอนอ่านผล
- ผล AI แกว่งทุกครั้ง — ดูเป็น % จากหลายรอบ ไม่สรุปจากคำตอบเดียว · เทียบข้ามสัปดาห์ด้วยถ้อยคำเดิมเท่านั้น
- SoV เป็นสูตรที่เรากำหนด (ถ่วงตำแหน่ง 1.0 / 0.8 / 0.6 / 0.4 / 0.2) ไม่ใช่ส่วนแบ่งตลาด — บอกตัวหารทุกครั้ง
- เว็บที่ถูกอ้างช่วยตั้งสมมติฐานว่า AI ใช้แหล่งไหน แต่ไม่ได้พิสูจน์ว่าเพราะอะไร AI จึงเลือกแบรนด์นั้น
- ChatGPT ต้องเปิด search ถึงจะเทียบได้ ถ้าวัดด้วยมือ
