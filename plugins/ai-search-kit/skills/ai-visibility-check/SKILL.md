# AI Visibility Check — แพ้ตรงไหน แพ้ใคร ต้องทำอะไร

ผลวัดเป็นแค่ตัวเลขจนกว่าจะแปลเป็นงาน skill นี้อ่านผล แล้วตอบ 3 คำถาม: **ไม่ถูกแสดงที่คำถามไหน · ใครถูกแสดงแทน · ควรทำอะไร และทำอย่างไร**

## 1. รับข้อมูล (แบบใดแบบหนึ่ง)
- **A. ไฟล์ export จากระบบวัดผล** (CSV คอลัมน์ `run_date … platform … brand_mentioned … cited_domains, answer_text`) ← แบบหลักในคลาส
- **B. ไฟล์ Excel จาก `prompt-finder`** ที่กรอกชีต "Tracking (วัดด้วยมือ)" แล้ว
- **C. คำตอบ AI ที่ copy มาวาง** — ให้ผู้ใช้บอก prompt + แพลตฟอร์มของแต่ละคำตอบ แล้วกรอกเป็นตารางตามคอลัมน์ของแบบ A เอง (ถูกเอ่ยไหม · ลำดับ · แบรนด์ที่ถูกเอ่ย · เว็บที่ถูกอ้าง) ก่อนวิเคราะห์
ถามเพิ่มเฉพาะที่ขาด: ชื่อแบรนด์ + ชื่อเรียกอื่น · คู่แข่ง · โดเมนเว็บเรา · (ถ้ามี) Brand Brain และ Prompt Set
- **ถ้อยคำ prompt ใช้ตามไฟล์ตรงตัว** — copy จาก CSV ของ Mention Lab (หรือไฟล์ Prompt Set) เท่านั้น ห้ามพิมพ์ prompt ใหม่หรือแก้วรรณยุกต์/ตัวสะกด ทั้งตอนรันสคริปต์ เขียนรายงาน และส่งต่อ skill อื่น · อ้างถึง prompt ด้วยรหัส P01–P10 คู่กับถ้อยคำจากไฟล์
- **Brand Brain:** หาไฟล์ `brand-brain-<แบรนด์>.md` ในโฟลเดอร์โปรเจกต์หรือไฟล์แนบ ถ้าไม่มี ให้บอกผู้ใช้ตั้งแต่ต้นว่า "ยังไม่มี Brand Brain — ข้อมูลที่ AI พูดใน prompt branded (ราคา ประกัน สเปก เงื่อนไข) ตรวจว่าถูกหรือผิดไม่ได้ จะติด **ต้องตรวจ** ไว้ทุกข้อ" แล้วทำต่อได้ (ไม่ต้องหยุดรอ)

## 2. คำนวณ
รัน `python3 scripts/analyze.py <ไฟล์> --brand <แบรนด์> --aliases "<ชื่อเรียกอื่น>" --prompts prompt-set-import-<แบรนด์>.csv --brain brand-brain-<แบรนด์>.md --out visibility-<แบรนด์>`
(ใส่ `--prompts` / `--brain` เฉพาะเมื่อมีไฟล์นั้น) ได้ `.md` (ตารางให้ผู้ใช้ดู) + `.json` (ตัวเลขให้คุณใช้วิเคราะห์ต่อ)
- สคริปต์จับคู่ผลกับ prompt ด้วยรหัส P01–P10 (ไม่ใช่ข้อความตรงตัว) · ถ้าถ้อยคำในไฟล์ผลไม่ตรงชุดเดิม หรือป้าย branded ไม่ตรงกับข้อความ (มี/ไม่มีชื่อแบรนด์) จะขึ้น `WARN:` และกล่อง "⚠️ ต้องดูก่อนอ่านผล" บนหัวรายงาน — **บอกผู้ใช้ก่อนตัวเลขทุกครั้ง**
- prompt ที่ป้าย branded ขัดกับข้อความ จะยังไม่นับในสถิติทั้ง 2 กลุ่ม → ถามผู้ใช้ว่าข้อนั้นควรเป็นกลุ่มไหน แก้ป้ายแล้วรันใหม่ · ไม่มีคอลัมน์ branded → สคริปต์คิดจากชื่อแบรนด์/ชื่อเรียกอื่นในข้อความ และแจ้งว่าคิดแบบนี้
- นับเฉพาะคำตอบ `status = ok` · แจ้งจำนวน error / ไม่มีคำตอบแยก
- แยก **non-branded** (AI เลือกเราไหม) กับ **branded** (AI พูดถึงเราถูกไหม) เสมอ ห้ามรวม
- สถานะต่อ prompt × แพลตฟอร์ม: **Lead / Chasing / Absent** (นิยามใน `references/action-playbook.md`)
ถ้ารันสคริปต์ไม่ได้ ให้คำนวณเองตามนิยามเดียวกัน และบอกผู้ใช้ว่าคำนวณมือ

## 3. วินิจฉัยและแนะนำ
อ่าน `references/action-playbook.md` แล้ว:
1. จับอาการต่อ prompt (A–F) — ใช้ `cited_domains`, `shown_instead`, `answer_text` เป็นหลักฐาน
2. Branded: อ่าน `answer_text` หาข้อมูลผิด/เก่า/ลบ เทียบกับ Brand Brain หรือเว็บทางการ (ถ้าไม่มีข้อมูลทางการให้ตรวจ บอกว่า "ต้องตรวจ" ไม่เดา) · ไม่มี Brand Brain = ทุกข้อเท็จจริงใน branded ติด "ต้องตรวจ" และงานแรกที่แนะนำคือทำ `brand-brain`
3. เลือก **งานสำคัญไม่เกิน 5 งาน** เรียงตามกติกาจัดลำดับ แต่ละงานต้องมี: ทำอะไร · ทำอย่างไร (ขั้นตอน 2–4 ข้อ) · prompt/หัวข้อที่เกี่ยว · ส่งต่อ skill ไหน · "เสร็จ" คืออะไร · วัดซ้ำเมื่อไร

## 4. ส่งผล
**ในแชต:**
0. ถ้ามีคำเตือนจากสคริปต์ (ถ้อยคำไม่ตรงชุดเดิม · ป้าย branded ขัดกับข้อความ · ไม่มี Brand Brain) แสดงเป็นกล่อง ⚠️ ก่อนอย่างอื่น
1. สรุป 3 บรรทัด: mention rate non-branded / branded · แพลตฟอร์มที่แข็ง/อ่อนที่สุด · คู่แข่งที่ถูกแสดงแทนบ่อยที่สุด
2. ตาราง prompt ที่ **Absent** และ **Chasing** + ใครถูกแสดงแทน + เว็บที่ถูกอ้าง
3. **งานที่ควรทำ ≤5 ข้อ** (ทำอะไร · ทำอย่างไร · ส่งต่อ skill)
4. ข้อควรระวังในการอ่านผล 1–2 บรรทัด (ผลแกว่ง, ดูแนวโน้มรายสัปดาห์)
**ไฟล์:** `visibility-<แบรนด์>.md` (ตาราง + งานที่ควรทำ) — ใน Cowork/Claude Code บันทึกในโฟลเดอร์โปรเจกต์ให้ skill อื่นอ่านต่อ
**ส่งต่อ:** prompt ที่เลือกไปทำ content → `ai-content-writer` · ข้อมูลที่ AI พูดผิด → `brand-brain` หัวข้อ 10 · งานทั้งหมด → `action-plan-30d` (กำลังมา — ระหว่างนี้ทำมือ: เอางาน ≤5 ข้อในไฟล์ `visibility-<แบรนด์>.md` ลงตารางรายสัปดาห์ สัปดาห์ละ 1–2 งาน แล้วดูผลทุกรอบวัด จ./พฤ.)
**ปิดท้ายเสมอด้วยคำสั่งถัดไป** ในกรอบ code ที่ copy ไปใช้ได้ทันที เติมชื่อไฟล์และ prompt จริงให้แล้ว เช่น `/ai-content-writer เขียนหน้าใหม่ตอบ prompt "<ถ้อยคำ P03 จากไฟล์>" สถานะ Absent เว็บที่ถูกอ้างคือ <โดเมน> ใช้ brand-brain-<แบรนด์>.md` (ยังไม่มี Brand Brain → `/brand-brain ทำ Brand Brain ของ <แบรนด์> เว็บ <URL>` ก่อน)

## รอบวัดซ้ำ (สัปดาห์ที่ 2–4 และวันที่ 30)
ถ้ามีผลหลายรอบ (`run_date` / `run_label` ต่างกัน) ให้รันสคริปต์แยกรอบ แล้วเทียบ: mention rate และ SoV ขึ้น/ลง ต่อแพลตฟอร์มและหัวข้อ · prompt ที่เปลี่ยนสถานะ (Absent → Chasing → Lead) · งานที่ทำไปแล้วสัมพันธ์กับ prompt ไหน — พูดเป็น "สัมพันธ์กัน" ไม่สรุปว่าเป็นสาเหตุ

## กติกา
- ห้ามสรุปจากคำตอบเดียว · ห้ามเรียกว่า "อันดับใน AI"
- ห้ามแต่งตัวเลขหรือเหตุผลที่ AI เลือกแบรนด์ — เว็บที่ถูกอ้างเป็นหลักฐานประกอบ ไม่ใช่ข้อพิสูจน์
- SoV ต้องบอกสูตรและตัวหาร (ถ่วงตำแหน่ง 1.0/0.8/0.6/0.4/0.2 ภายในแพลตฟอร์มเดียวกัน)
- สินค้าสุขภาพ / อาหาร-เครื่องดื่ม / การเงิน: ข้อมูลผิดใน branded = งานลำดับแรกเสมอ
- อ้างอิงแนวคิด: *AI SEO For Dummies* (Nathan Gotch, Wiley 2026) บทที่ 5, 7, 8 (baseline, SoV, citation gap, วัดซ้ำ) และ 10–12, 14, 16–20 (แนวทางแก้) + SparkToro × Gumshoe (ม.ค. 2026) เรื่องผล AI แกว่ง — สรุปด้วยคำของเรา ไม่คัดลอกข้อความจากหนังสือ
