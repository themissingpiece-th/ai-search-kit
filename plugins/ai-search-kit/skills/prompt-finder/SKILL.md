# Prompt Finder v2 — เลือก prompt ด้วย Prompt Map

ใน AI Search เราวัดเป็น **prompt** ไม่ใช่ keyword และ prompt ไม่มี search volume — ผลวัดจะมีความหมายก็ต่อเมื่อเลือก prompt ถูก skill นี้ทำให้การเลือกมีเหตุผลและทำซ้ำได้
อ่าน `references/prompt-map.md` ก่อนเริ่มทุกครั้ง

## 1. ขอข้อมูล (ถามรวดเดียว เฉพาะที่ขาด)
- **แบรนด์** + **ชื่อเรียกอื่น** (ไทย / อังกฤษ / ชื่อย่อ เช่น "BYD, บีวายดี")
- **สินค้า/บริการหลัก** 1–3 อย่าง + เว็บไซต์
- **กลุ่มลูกค้า** และเงื่อนไขจริงของเขา (งบ ปัญหา สถานการณ์ใช้ พื้นที่)
- **คู่แข่ง** 3–5 ราย (+ ชื่อเรียกอื่น)
- ตลาด/ภาษา (ค่าเริ่มต้น: ไทย / ภาษาไทย)
- (ไม่บังคับ แต่ทำให้ผลดีขึ้นมาก) **หลักฐานความต้องการ**: คำถามลูกค้าจริง, ไฟล์ GSC, keyword/AI search volume
ถ้าผู้ใช้ยังไม่มีธุรกิจของตัวเอง ใช้เคสตัวอย่าง: **BYD · รถยนต์ไฟฟ้า · คนเมืองซื้อ EV คันแรก · คู่แข่ง MG, Tesla, Deepal, Neta, GWM ORA**

## 2. ทำ Prompt Map ทีละขั้น (บอกผู้ใช้สั้น ๆ ว่าอยู่ขั้นไหน)
1. **Demand** — สรุปหลักฐานความต้องการเป็น 5–8 หัวข้อ ระบุว่ามาจากแหล่งไหน ถ้าไม่มีหลักฐานให้บอกตรง ๆ ว่าเป็น "AI ช่วยคิด"
2. **Journey** — ร่าง prompt ผู้สมัคร ~24–30 ข้อ กระจาย Discovery / Evaluation / **Comparison / Decision** (เน้น 2 ขั้นหลัง)
3. **Prompt Anatomy** — ทุกข้อต้องมี สินค้า + บริบทผู้ถาม + เจตนาขอคำแนะนำ + เกณฑ์ตัดสินใจ · เพิ่ม branded 5–6 ข้อ (ราคา/สเปก · เทียบคู่แข่ง · ข้อเสีย)
4. **Topic** — จัดกลุ่มตามเกณฑ์ตัดสินใจ แล้วถามผู้ใช้ว่าจะโฟกัส **2–3 หัวข้อ** ไหน (เสนอตัวเลือกพร้อมเหตุผล ถ้าผู้ใช้ไม่ตอบให้เลือกตามคะแนน)
5. **Score & Set** — ให้คะแนน 5 ด้าน (business 30 · demand 20 · mention 20 · win 15 · risk 15) แล้วคัด **non-branded 7 + branded 3** ตามกติกาใน reference

## 3. ส่งผล
1. เขียน JSON ตามรูปแบบใน `scripts/make_outputs.py` แล้วรัน
   `python3 scripts/make_outputs.py prompts.json <แบรนด์>`
   ได้ 2 ไฟล์ (ถ้าไม่มี openpyxl ให้ `pip install openpyxl` ก่อน):
   - `prompt-set-<แบรนด์>.xlsx` — ชีต Prompt Set · ผู้สมัครทั้งหมด · Tracking (วัดด้วยมือ) · วิธีใช้
   - `prompt-set-import-<แบรนด์>.csv` — **ไฟล์สำหรับนำเข้าระบบวัดผล** (คอลัมน์ prompt, topic, branded, stage, source, score, why)
2. ในแชตแสดง:
   - ตาราง 10 ข้อ: prompt · หัวข้อ · branded? · ขั้น · คะแนน · ทำไม
   - สรุป 1 บรรทัด: ครอบคลุมหัวข้ออะไร และข้อไหนมาจากหลักฐานจริง / ข้อไหน AI ช่วยคิด
   - ขั้นต่อไป: นำเข้าไฟล์ CSV ในระบบวัดผล (หรือวัดด้วยมือตามชีต Tracking) → อ่านผลด้วย skill `ai-visibility-check`

## กติกา
- ภาษาเดียวกับลูกค้า ใช้คำที่คนพิมพ์จริง · **ห้ามใส่ปี** · non-branded ห้ามมีชื่อแบรนด์เรา
- **ห้ามแต่งตัวเลข volume** หรือ "ความนิยม" ของ prompt — ใช้เฉพาะตัวเลขที่ผู้ใช้ให้มาหรือดึงจากเครื่องมือจริง และบอกว่าเป็นค่าประมาณ
- prompt ที่ `source = ai` ต้องบอกผู้ใช้ให้เทียบกับคำถามลูกค้าจริงก่อนใช้
- สินค้าการเงิน / สุขภาพ / อาหาร-เครื่องดื่ม: prompt คือคำถามของลูกค้า — อย่าใส่ข้อมูลสินค้า (ราคา ส่วนผสม สรรพคุณ) ที่ยังไม่ได้ตรวจจากแหล่งทางการ และให้ risk = 3
- แยก branded กับ non-branded เสมอ ห้ามรวมเป็นคะแนนเดียว
- อ้างอิงแนวคิด: Nathan Gotch, *AI SEO For Dummies* (Wiley 2026) บทที่ 5, 9 — สรุปด้วยคำของเรา ไม่คัดลอกข้อความจากหนังสือ
